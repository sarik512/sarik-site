# Сайт Sarik

Статический одностраничный сайт: обо мне, увлечения, проекты, ссылки, контакты.
Файлы:
- `index.html` — весь сайт (один файл, стили и скрипты внутри)
- `assets/sarik.jpg` — фото профиля
- `assets/og-image.jpg` — превью для соцсетей/мессенджеров при пересылке ссылки

## Что нужно доделать перед публикацией

В `index.html` помечено `TODO` / `URL?` в нескольких местах — замени на реальные данные:

1. **Ссылки в разделе "Все ссылки"** — сейчас 4 пункта ведут в никуда (`href="#"`):
   - «Мои желания» — ссылка на вишлист
   - «Sarik's world» — ссылка на телеграм-канал
   - «School 21» — стоит общий `21-school.ru`, замени на свой профиль
   - «GitHub» — добавь свой юзернейм и ссылку
2. **Email в форме контактов** — найди в конце файла строку
   `const to = 'your-email@example.com';` и замени на настоящую почту.
3. **og:url** в `<head>` — после публикации замени `https://your-domain-here.example/`
   на реальный адрес сайта (нужно для красивого превью в мессенджерах).

## Как опубликовать бесплатно (GitHub Pages)

1. Создай новый репозиторий на GitHub, например `sarik-site`.
2. Загрузи в него `index.html` и папку `assets/` (через веб-интерфейс: "Add file → Upload files", или через git).
3. В репозитории зайди в **Settings → Pages**.
4. В разделе "Build and deployment" выбери **Deploy from a branch**, ветку `main`, папку `/root` → **Save**.
5. Через 1–2 минуты сайт будет доступен по адресу вида:
   `https://твой-юзернейм.github.io/sarik-site/`

Свой домен (например `sarik.me`) можно подключить там же, в Pages → Custom domain.

## Альтернативы (тоже бесплатно, ещё проще)

- **Netlify** (netlify.com) — перетаскиваешь папку с сайтом на сайт, готово.
- **Vercel** (vercel.com) — импортируешь репозиторий с GitHub, деплой автоматом.

## Локальная проверка

Просто открой `index.html` в браузере — сайт полностью автономный,
сервер не нужен.
